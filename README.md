# English Apps · Anuncio en vídeo

Anuncio animado y narrado (≈ 1 min) de **[English Apps](https://nuriacalvo-teacher.github.io/)**, las aplicaciones interactivas de inglés creadas por **Nuria Calvo**, profesora de inglés del IES Goya (Zaragoza).

- `index.html` → versión en inglés (narración con las voces del navegador, igual que la app BRIT).

## Cómo verlo

Abre `index.html` en el navegador (o actívalo con GitHub Pages: *Settings → Pages → Deploy from a branch → main*) y pulsa el botón de reproducir, con el sonido activado.

- La voz la pone el propio dispositivo: se elige automáticamente la mejor voz disponible (Google, Microsoft «Natural», Apple mejorada/Siri) y se puede cambiar en el desplegable **Voice** antes de empezar.
- La música se genera en directo en el navegador; se puede silenciar con el botón de la nota musical.
- El botón de la esquina inferior derecha pone el vídeo a pantalla completa (ideal para proyectarlo en la pizarra digital).
- Un único fichero HTML, sin instalaciones ni dependencias (solo carga las fuentes de Google Fonts).
